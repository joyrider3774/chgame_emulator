Programs load from a file on this computer, from a URL, or with ?rom=name.bin from the folder the emulator is in (?rom=https://… works for any address that allows it). A games.json beside the page — a list of file names — fills the Games menu.

?sd=card.zip or ?sd=card.img (beside the page or a full URL) fills the microSD card from a zip file or a card image, once: the card then keeps what programs write to it until the file changes. Without ?sd=, a sdcard.zip or sdcard.img beside the page is used the same way. Manage… shows the card's files.
